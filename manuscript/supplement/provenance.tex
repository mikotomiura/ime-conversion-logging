\section*{Provenance of the result files}
\label{sec:supp-provenance}

Every result file was made from an export of a freezing tag of the public repository. Where a deviation replaced a
file of the export, the replacing file is the one of release \texttt{v1.0.0}, with these SHA-256:
\begin{itemize}
\item \texttt{kit/analysis/match.py} (D10):\\
{\footnotesize\texttt{6f817228e2e7d5f17f65895c7a00a721c28c00df24c46df0c8bd4b237ad72cff}}
\item \texttt{kit/e2/closed\_set.py} (D8):\\
{\footnotesize\texttt{364cc833b48a73aeb15b9416bff203ec21a71296e26534f914e3a2bb9bd067c3}}
\end{itemize}
The records of the runs (\texttt{experiment/data.md} for macOS and \texttt{experiment/data.windows.md} for Windows)
give, for every row, the machine, the version of Python, the command and the SHA-256 of every output. Paths are
relative to \texttt{experiment/results}.
